🧪 Test Cases (Autoguardado en localStorage)

📌 Test Case 1: Validar precondiciones BrandBrain

⚠️ Pre-requisito: Se requiere una sesión con BrandBrain iniciado. Si no tienes una, inicia una sesión nueva primero.
  1. Abre https://brand-studio-agent.onrender.com en Google Chrome
  2. Haz Ctrl+Shift+R para limpiar caché de app.js (obligatorio)
  3. Ingresa con tu cuenta Google
  4. Navega a la sección Brand Brain y confirma que tienes 9/9 sections completadas
✅ Resultado esperado: Todas las 9 secciones muestran estado "confirmado" o "completado". El botón de Catalog NO aparece o muestra "X/9 sections completed".
❌ No debe pasar: Botón Catalog aparece con estado diferente a 9/9 o BrandBrain tiene secciones pendientes.

📌 Test Case 2: Validar Brand Soul generado

⚠️ Pre-requisito: BrandBrain debe tener 9/9 sections.
  1. Desde BrandBrain 9/9, navega a la sección Brand Soul
  2. Si Brand Soul NO está generado, haz clic en "Generate Brand Soul" (cuesta 20 créditos)
  3. Espera a que se complete la generación (aparece el contenido de Brand Soul)
✅ Resultado esperado: Brand Soul muestra contenido generado verificable. No hay mensaje de "Brand Soul no generado" o error.
❌ No debe pasar: Error como "Brand Soul es un prerequisito" o UI vacía sin contenido.

📌 Test Case 3: Botón Catalog habilitado

⚠️ Pre-requisitos: BrandBrain 9/9 + Brand Soul generado.
  1. Con BrandBrain 9/9 y Brand Soul generado, busca el botón "Catalog — 9/9 sections ready" en la UI
  2. Verifica que el botón está habilitado (opaco, clickable)
✅ Resultado esperado: Botón "Catalog — 9/9 sections ready" aparece y está habilitado.
❌ No debe pasar: Botón Catalog ausente, deshabilitado (gris), o muestra estado incorrecto.

📌 Test Case 4: Generar Catalog (15 créditos)

⚠️ Pre-requisitos: Botón Catalog habilitado + créditos suficientes (≥15).
  1. Haz clic en "Catalog — 9/9 sections ready"
  2. Verifica que el modal de créditos aparece (credit gate modal)
  3. Si el modal no aparece, es porque el catálogo ya está cacheado (normal)
  4. Haz clic en "Generate Catalog" en el modal (o ve directo al catalog si ya existe)
  5. Espera a que cargue la vista de 30 ideas en 3 columnas
✅ Resultado esperado: Se muestran exactly 30 ideas en 3 columnas de layout. Créditos se deducen -15. No hay error "400 No se pudo extraer un nicho".
❌ No debe pasar: Error "Brand Soul es un prerequisito", error 400 nich extraction, paywall (402), o menos de 30 ideas.

📌 Test Case 5: Research Tools Integration (WebSearch, YouTube, Trends)

⚠️ Pre-requisito: Catalog cargado con 30 ideas visibles.
  1. En cualquier idea, busca los 3 botones de investigación: WebSearch, YouTube, Trends
  2. Haz clic en uno de los botones (ej: "WebSearch")
  3. El botón debe mostrar loading state "..." durante la petición
  4. Espera la respuesta del API (demora ~5-15 segundos)
  5. Verifica que aparece un alert de éxito: "✅ WEBSEARCH investigation complete!"
  6. Verifica que tus créditos se actualizan (cuesta 25 créditos por cada investigación)
✅ Resultado esperado: Botón muestra "..." → alert de éxito → créditos deducidos -25 → UI sigue cargada sin errores.
❌ No debe pasar: Error alert "Research API error", paywall 402 sin redirect, o botón stuck en "..." para siempre.

📌 Test Case 6: Approve/Reject Ideas con feedback visual

⚠️ Pre-requisito: Catalog cargado.
  1. Haz clic en el botón ✓ (approve) de una idea
  2. Verifica que el contenedor de la idea cambia a fondo verde claro con borde izquierdo verde
  3. Haz clic en el botón ✗ (reject) de otra idea
  4. Verifica que el contenedor cambia a fondo rojo claro con borde izquierdo rojo
  5. Intenta hacer toggle (click approve luego reject) para verificar cambio de estado
✅ Resultado esperado: Ideas approved muestran fondo verde (#F0FDF4) + borde verde. Ideas rejected muestran fondo rojo (#FEF2F2) + borde rojo. Toggle funciona fluido.
❌ No debe pasar: Sin cambio visual, colores incorrectos, o toggle no responde.

📌 Test Case 7: Lock Catalog Button (todas las ideas reviewed)

⚠️ Pre-requisito: Catalog cargado.
  1. Busca el botón "Lock Catalog" (debe estar deshabilitado/gris al inicio)
  2. Approve o reject todas las 30 ideas (puedes hacer bulk approve rápido)
  3. Ve al botón "Lock Catalog" y verifica que ahora está habilitado
  4. Haz clic en "Lock Catalog"
  5. Verifica que aparece un alert de éxito o la UI muestra estado "locked"
✅ Resultado esperado: Botón "Lock Catalog" se habilita solo cuando 30/30 ideas están approved/rejected. Click en "Lock Catalog" completa la acción sin errores.
❌ No debe pasar: Botón Lock permanece deshabilitado con todas las ideas reviewed, o error al intentar lock.

📌 Test Case 8: Error Handling - Brand Brain Incompleto

⚠️ Pre-requisito: Ninguno (test de caso negativo, idealmente en sesión nueva con BrandBrain < 9/9).
  1. Abre una nueva sesión (logout y login de nuevo)
  2. No completes BrandBrain (déjalo con < 9/9 sections)
  3. Intenta hacer clic en "Catalog" (si aparece) o navega a la sección
✅ Resultado esperado: Alert de error "Brand Brain no está completo. Completa las 9 secciones primero." O botón Catalog montrando estado actual (<9/9).
❌ No debe pasar: El sistema permite generar Catalog sin BrandBrain completo, o el error no es claro.

📌 Test Case 9: Error Handling - Brand Soul Faltante

⚠️ Pre-requisito: BrandBrain 9/9 pero Brand Soul NO generado.
  1. En una sesión con BrandBrain 9/9 pero sinn Brand Soul generado
  2. Haz clic en "Catalog"
✅ Resultado esperado: Alert de error "Brand Soul es un prerequisito para generar el catálogo. Primero genera tu Brand Soul para continuar."
❌ No debe pasar: Catalog se genera sin Brand Soul, o el error no menciona Brand Soul.

📌 Test Case 10: Paywall Handling (créditos insuficientes)

⚠️ Pre-requisito: Sesión con créditos < 15 (para Catalog) o < 25 (para investigación).
  1. Deja tu sesión con pocos créditos (< 15). Si no puedes, este test es opcional.
  2. Intenta generar Catalog o hacer una investigación
✅ Resultado esperado: Paywall modal aparece automáticamente con botón "Buy Credits" y URL de pago. No hay error 402 crudo en la UI.
❌ No debe pasar: Error 402 en consola sin modal, o el sistema permite gastar sin créditos.
